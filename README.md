# PizzaDev

Aplicativo de gestão de comandas de pizzaria desenvolvido com Python e Flet.

## Funcionalidades

- Seleção de pizzas por card
- Escolha do tamanho da pizza: P, M e G
- Adição de itens ao pedido
- Agrupamento automático por pizza e tamanho
- Controle de quantidade com botões de + e -
- Remoção individual de item
- Cancelamento do pedido
- Cadastro de cliente, mesa e observações
- Resumo do total do pedido
- Envio do pedido para a cozinha
- Finalização do pedido

## Tecnologias

- Python 3
- Flet

## Requisitos

- Python 3.10 ou superior
- Biblioteca Flet instalada

## Instalação

```bash
pip install -r requirements.txt
```

## Execução

```bash
python main.py
```
